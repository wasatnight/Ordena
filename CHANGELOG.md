# Changelog

## 1.1.1 — 2026-10-23

- Corrected the requested palette: pale pink throughout the interface, with blue text and matching controls, popups, rule editor and help.
- Shortened the subtitle to Your folders, organized / Tus carpetas ordenadas.
- Preserved the layout, original application icon, stable selections and file safety behavior.

## 1.1.0 — 2026-10-23

- Original Windows app icon, with nine sizes, set on the executable and application windows; explicit taskbar identity.
- Soft near-white blush replaces the mint accent throughout the interface and controls.
- Centered brand with a matching, smaller subtitle underneath.
- Stable file selection: click a checkbox or file name, or press Space. Table items, keyboard focus and scroll position are preserved. Full-row highlight and native focus rectangle removed from the preview.
- Category controls toggle all/none, while displaying partial selection clearly.
- Styled language popup and clearer hover/focus/pressed states.
- Replaced the inline instructional sentence with a ? button containing offline steps, examples and safety explanations in English and Spanish.
- Nine interface regression checks added (44 tests total); executable icon resources and packaged icon loading verified during Windows builds.

## 1.0.0 — 2026-10-23

Initial preview-first folder organization, editable rules, safe Windows moves, persistent undo and English/Spanish interface.
